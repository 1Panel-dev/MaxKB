## Overview

MySQL Query is a tool that connects to a MySQL database and runs SQL queries.

## Configuration

1. Configure startup parameters in the Function Library.
   Open the MySQL function panel, click **... -> Startup Parameters**, fill in database connection settings, and enable the function.
   ![Startup parameters](/admin/tool/img/MySQL_setting.jpg)
2. Use in an application.
   In an advanced orchestration app, go to **Add Component -> Function Library -> MySQL Query** and set the query content.
   ![Use in app](/admin/tool/img/MySQL_app_used.jpg)
