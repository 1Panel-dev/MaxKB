## Overview

LangSearch is a search tool that provides multilingual web search results for LLM applications.

## Configuration

1. Configure startup parameters in the Function Library.
   Open the LangSearch function panel, click **... -> Startup Parameters**, fill in required credentials, and enable the function.
2. Use in an application.
   In an advanced orchestration app, go to **Add Component -> Function Library -> LangSearch** and configure parameters.
