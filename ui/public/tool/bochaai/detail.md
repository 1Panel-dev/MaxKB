## Overview

BochaAI Search is a search tool used to retrieve web results through the BochaAI service.

## Configuration

1. Configure startup parameters in the Function Library.
   Open the BochaAI function panel, click **... -> Startup Parameters**, fill in required credentials, and enable the function.
2. Use in an application.
   In an advanced orchestration app, go to **Add Component -> Function Library -> BochaAI Search** and configure parameters.
