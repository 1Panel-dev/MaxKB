# 安全说明

谢绝只有静态代码分析未经完整PoC验证，以及完全由AI生成未经人工PoC验证的安全建议。

# Security Policy

Any security issue please [submit a vulnerability report](https://github.com/1Panel-dev/MaxKB/security/advisories/new).

We do not accept the security recommendations which are based solely on static code analysis and generated by AI without manual PoC validation.

Thanks for your support!
